# Роль Skill

Этот Skill отвечает за финальную обработку результатов рыночного исследования стоимости логистики.

Он НЕ выполняет основной поиск компаний вместо специализированных субагентов.

Поиск выполняют:
- `market-auto` — автомобильные перевозки;
- `market-rail` — железнодорожные перевозки;
- `market-sea` — морские перевозки;
- `market-air` — авиационные перевозки.

Skill получает результаты одного или нескольких субагентов, проверяет их, приводит к единому формату и формирует итоговый файл для руководителя.

# Когда использовать

Используй Skill автоматически, если пользователь просит:
- анализ рынка стоимости логистики;
- сравнение ставок перевозчиков или экспедиторов;
- анализ стоимости перевозки по маршруту;
- сравнение Авто / ЖД / Море / Авиа;
- анализ FCL / LCL;
- подготовку сводного отчёта по рыночным ставкам.

Если пользователь запрашивает только один вид перевозки, используй результаты соответствующего субагента.

Если пользователь просит полный анализ рынка, сначала должны отработать все необходимые субагенты, затем запускай этот Skill.

# Входные данные

Skill должен получить от субагентов структурированные данные минимум со следующими полями:

- Наименование организации
- Вид перевозки
- Тип перевозки / загрузки
- Маршрут перевозки
- Стоимость за 1 КГ
- Стоимость за 1 М3
- Стоимость за одно транспортное средство / контейнер / вагон / грузовую единицу
- Валюта
- Дата актуальности цены
- Источник
- Комментарии
- Отзывы о компании

# Обязательные ограничения

## Количество компаний

Для полного анализа рынка:
- не менее 50 компаний;
- не более 100 компаний.

От одной компании:
- не более 3 цен.

Если невозможно подтвердить минимум 50 компаний с актуальными ценами, НЕ добавляй устаревшие или неподтверждённые данные для достижения лимита.

В отчёте укажи:
- сколько компаний реально найдено;
- сколько прошло проверку;
- почему не удалось достичь 50, если это произошло.

# Актуальность

В итоговый отчёт включай только цены, у которых дата публикации, обновления или подтверждения не старше 1 месяца относительно даты анализа.

Исключай:
- цены старше 1 месяца;
- цены без подтверждаемой даты актуальности;
- устаревшие прайс-листы;
- архивные предложения;
- цены, которые невозможно связать с конкретной компанией.

# Проверка источников

Приоритет:
1. официальный сайт компании;
2. официальный калькулятор;
3. официальный тариф или прайс-лист;
4. свежее коммерческое предложение;
5. официальный профиль/публикация компании;
6. отраслевой агрегатор — только как дополнительный источник.

По возможности проверяй цену на официальном ресурсе.

Если цена указана как «от ...», отметь это в комментарии.

# Удаление дублей

Перед формированием отчёта:
1. нормализуй наименования компаний;
2. найди дубли;
3. объедини повторные записи одной компании;
4. оставь не более 3 цен от одной компании;
5. не допускай повторов одной и той же цены из разных страниц одного сайта.

# FCL / LCL и тип загрузки

Используй FCL и LCL только там, где эти обозначения применимы.

Для других перевозок используй корректные отраслевые обозначения:
- FTL;
- LTL;
- сборный груз;
- отдельное ТС;
- контейнер;
- вагон;
- авиагруз;
- чартер;
- иное фактическое обозначение.

Не переименовывай тип перевозки в FCL/LCL искусственно.

# Нормализация стоимости

Используй следующие основные поля:

1. `Стоимость за 1 КГ`
2. `Стоимость за 1 М3`
3. `Стоимость за одно транспортное средство / контейнер / вагон / грузовую единицу`

Если цена уже дана в нужной единице — перенеси без изменения.

Если требуется пересчёт:
- выполняй его только при наличии достаточных исходных данных;
- сохраняй исходные параметры;
- фиксируй формулу или способ пересчёта в комментарии.

Если пересчитать достоверно невозможно:
- не придумывай значение;
- оставь ячейку пустой;
- поясни причину в `Комментарии`.

# Валюта

Не скрывай валюту исходного тарифа.

В колонке `Валюта` указывай исходную валюту.

Если пользователь отдельно просит привести всё к одной валюте:
- используй актуальный курс на дату анализа;
- добавь исходную валюту и курс в комментарий;
- не заменяй исходную цену без возможности восстановить первоначальное значение.

# Дополнительные расходы

По возможности отмечай, включены ли:
- топливные надбавки;
- терминальные расходы;
- портовые расходы;
- станционные сборы;
- страхование;
- таможенное оформление;
- доставка первой/последней мили;
- дополнительные сборы перевозчика.

Если состав тарифа неизвестен — укажи это.

# Отзывы

Поле `Отзывы о компании` необязательно.

Заполняй только если найдены релевантные отзывы.

Не выдавай единичный отзыв за общую репутацию компании.

Не придумывай оценки.

# Сортировка

Сортируй от минимальной стоимости к максимальной.

Если пользователь указал единицу сравнения — сортируй по ней:
- за 1 КГ;
- за 1 М3;
- за транспортное средство / контейнер / вагон / грузовую единицу.

Если пользователь не указал единицу:
- выбери наиболее релевантную для данного запроса;
- явно укажи в итоговом отчёте, по какому полю выполнена сортировка.

Не смешивай в одной сортировке несопоставимые ставки.

Если исследуются разные виды перевозки, допускается:
- отдельная сортировка внутри каждого вида;
- отдельные листы Excel;
- сводный лист с пояснением.

# Формат Excel

По умолчанию создавай `.xlsx`.

Рекомендуемая структура книги:

## Лист `Сводный анализ`

Колонки:
1. Наименование организации
2. Вид перевозки
3. Тип перевозки / загрузки
4. Маршрут перевозки
5. Стоимость за 1 КГ
6. Стоимость за 1 М3
7. Стоимость за транспортное средство / контейнер / вагон / грузовую единицу
8. Валюта
9. Дата актуальности цены
10. Источник
11. Комментарии
12. Отзывы о компании

## Отдельные листы

Если исследовано несколько видов перевозки, создай отдельные листы:
- `Авто`
- `ЖД`
- `Море`
- `Авиа`

Создавай только те листы, по которым есть результаты.

## Лист `Методология`

Укажи:
- дату анализа;
- маршрут;
- запрос пользователя;
- исследованные виды перевозки;
- критерий актуальности;
- число найденных компаний;
- число включённых компаний;
- число исключённых компаний;
- причины исключения;
- критерий сортировки;
- ограничения исследования.

# Визуальная проверка Excel

Перед завершением:
- проверь читаемость заголовков;
- включи автофильтр;
- закрепи строку заголовков;
- выставь разумную ширину колонок;
- даты храни как даты;
- числовые ставки храни как числа, а не текст;
- не объединяй ячейки в таблице данных;
- не удаляй пустые поля, если цена в соответствующей единице неизвестна.

# Сохранение

Итоговый файл ОБЯЗАТЕЛЬНО сохраняй в папку:

`отчёты/`

Если папки нет и среда позволяет — создай её.

Имя файла:

`анализ_рынка_логистики_<маршрут>_<YYYY-MM-DD>.xlsx`

Пример:

`анализ_рынка_логистики_Шанхай_Москва_2026-09-10.xlsx`

Используй безопасное имя файла без недопустимых символов.

# Финальная проверка

Перед завершением проверь:

1. Итоговый файл существует.
2. Файл открывается.
3. Колонки соответствуют требованиям.
4. Нет дублей компаний/ставок.
5. От одной компании не более 3 цен.
6. Нет цен старше 1 месяца.
7. Нет цен без подтверждённой даты актуальности.
8. Все источники сохранены.
9. Пустые пересчёты не заполнены выдуманными значениями.
10. Сортировка выполнена корректно.
11. Количество компаний находится в диапазоне 50–100 либо явно объяснено, почему минимум 50 недостижим.
12. Файл сохранён в `отчёты/`.

# Финальный ответ главного агента

После создания отчёта кратко сообщи пользователю:

- путь к файлу;
- дату анализа;
- маршрут;
- какие виды перевозки исследованы;
- сколько компаний проверено;
- сколько компаний вошло в отчёт;
- сколько цен вошло в выборку;
- по какому показателю выполнена сортировка;
- какие ограничения остались.

Не считай задачу завершённой, пока итоговый Excel-файл не создан и не проверен.
