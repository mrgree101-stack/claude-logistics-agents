# AI-ассистент руководителя отдела логистики

Пользователь формулирует рабочую задачу обычным языком — система сама определяет тип задачи, выбирает нужного субагента или Skill, выполняет работу, проверяет результат и возвращает готовый итог.

---

## Проблема

Руководитель отдела логистики ежедневно решает однотипные, но трудоёмкие задачи:

- отслеживать изменения законодательства по перевозкам, ЭПД и ЭТрН и понимать их практические последствия;
- сравнивать рынок стоимости перевозок (авто, ЖД, море, авиа) по актуальным ставкам — вручную это часы поиска по десяткам сайтов;
- проверять достоверность отраслевых новостей перед тем, как действовать или публиковать их;
- готовить деловые тексты: инструкции, регламенты, поручения, отчёты, посты для Telegram и Instagram.

Обычный чат с AI-моделью решает это плохо: модель «с ходу» отвечает на вопросы про актуальные нормы, придумывает цены и даты, а результат приходится вручную доводить до готового вида. Проект закрывает это: вся работа с актуальной информацией делегируется специализированным субагентам с жёсткими правилами достоверности, а результаты сохраняются в структурированном виде.

## Пользователь

Персональный ассистент руководителя отдела логистики / транспортной экспедиции. Также полезен сотрудникам смежных ролей: специалистам ВЭД, логистам, SMM-редактору отраслевого канала.

## Основная функция

Система работает на Claude Code: главный агент — координатор, специализированные субагенты — исполнители.

**Вход:** запрос обычным языком. Например:

- «Что изменилось по ЭТрН с 1 сентября?»
- «Собери ставки по морским контейнерным перевозкам Китай — Москва»
- «Преврати эту новость в пост для Telegram и Instagram»
- «Проанализируй ситуацию и подготовь регламент»

**Выход:** готовый рабочий материал — отчёт, таблица Excel, публикация, инструкция — с указанием источников, дат актуальности и ограничений.

**Задействованные инструменты:**

- субагенты `.claude/agents/` — исследование и анализ;
- Skills `.claude/skills/` — оформление публикаций и методика рыночного анализа;
- интернет-поиск и проверка источников (субагентами);
- Python (openpyxl) — формирование итоговых Excel-отчётов.

### Субагенты

| Субагент | Зона ответственности |
|---|---|
| `research-logistics` | Исследование по логистике, перевозкам, ЭПД, ЭТрН и законодательству: поиск, проверка дат, статуса норм, переходных положений |
| `market-auto` | Рынок ставок автомобильных перевозок (FTL/LTL, сборные грузы, международные и внутренние направления) |
| `market-rail` | Рынок ставок железнодорожных перевозок (вагоны, контейнеры, сборные отправки) |
| `market-sea` | Рынок ставок морских перевозок (FCL/LCL, контейнерные линии) |
| `market-air` | Рынок ставок авиаперевозок (генеральные и сборные грузы) |
| `logistics-smm` | Анализ отраслевого источника и подготовка достоверного материала для публикаций |

### Skills

| Skill | Что делает |
|---|---|
| `Logistics Market Analysis` | Методика сравнительного анализа рынка ставок по видам перевозок и формат итогового отчёта |
| `logistics-news-to-social` | Превращает один отраслевой источник в готовые публикации для Telegram и Instagram в заданной стилистике |

### Ключевые правила достоверности

- Цены — только актуальные (не старше 1 месяца), с зафиксированным источником и датой; цена без подтверждаемой даты в отчёт не включается.
- Выборка рынка — 50–100 компаний, не более 3 цен от одной компании, приоритет официальным сайтам и прайс-листам.
- Нормы — проверяются по названию документа, номеру, дате, статусу, дате вступления в силу и переходным положениям; действующие нормы не смешиваются с принятыми, но не вступившими.
- Ничего не придумывается: если данных недостаточно для пересчёта или вывода — поле остаётся пустым с пояснением, а не заполняется догадкой.

## Формат результата

- **Рыночный анализ** — файл `.xlsx` в папке `отчёты/`, например `анализ_рынка_логистики_Китай_Москва_2026-09-10.xlsx`: единая таблица (компания, вид и тип перевозки, маршрут, цена за кг/м³/транспортную единицу, валюта, дата актуальности, источник, комментарии), отсортированная по выбранной единице сравнения, с отчётом о размере выборки и ограничениях.
- **Обзор законодательства / новостей** — структурированный отчёт `.md` в `отчёты/`: суть изменений, кого касается, практические последствия, источники, дата актуальности.
- **Публикации** — готовые тексты для Telegram и Instagram + JSON-файл контента.
- **Рабочие материалы** — инструкции, регламенты, поручения, сводки.

## Технологии

- **Платформа:** Claude Code (агентная среда), модель Claude;
- **Конфигурация:** декларативные субагенты и Skills в Markdown с YAML-фронтматтером (`.claude/agents/*.md`, `.claude/skills/*/SKILL.md`);
- **Язык основного скрипта:** Python 3 (библиотека `openpyxl` для генерации Excel-отчётов);
- **Форматы данных:** Markdown (отчёты, регламенты), Excel `.xlsx` (рыночные выборки), JSON (контент публикаций);
- **Язык работы:** русский.

### Как работает система

```text
Запрос пользователя (обычный язык)
        │
        ▼
Главный агент (CLAUDE.md) ── определяет тип задачи
        │
        ├─► research-logistics ── актуальная информация, нормы, даты
        ├─► market-auto / rail / sea / air ── сбор актуальных ставок
        ├─► logistics-smm ── достоверный материал для публикаций
        │
        ▼
Проверка результата главным агентом
(полнота, достоверность, дубли, актуальность, ≤3 цен на компанию)
        │
        ▼
Готовый итог: отчёт .md / .xlsx, публикация, инструкция
        └── сохранение в отчёты/ и отчёт пользователю
```

## Начало работы

1. Установите Claude Code.
2. Скопируйте папку проекта и откройте её как рабочую директорию.
3. Сформулируйте задачу обычным языком — главный агент сам выберет исполнителя.

## Принципы

Приоритет системы: **Достоверность → практическая польза → понятность → оформление.** Исходные документы не изменяются; все результаты создаются новыми файлами; спорные и неподтверждённые сведения помечаются явно.
